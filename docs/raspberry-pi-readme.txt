ArduinoPath for Raspberry Pi
============================

Learn to code Arduino and ESP boards, step by step.
Made by the Banyule Nillumbik Tech School (BNTS).

Needs: a Raspberry Pi 4 or 5 with 64-bit Raspberry Pi OS (with the desktop).

To start: double-click "ArduinoPath" in this folder (choose Execute if the Pi asks).
It opens in Chromium. The first time, it adds itself to the menu (Education)
and puts an ArduinoPath icon on the desktop.

Then plug your Arduino or ESP board into the Pi's USB port.

Students' work is saved on this Pi, in ~/.config/ArduinoPath.
Remember: unplug the USB cable before you change any wires.

Help for teachers: docs/raspberry-pi.md in the ArduinoPath repository on GitHub
(github.com/jackallen28/BNTS_ArduinoPath).
